# x-scraper

X(Twitter)에서 특정 계정의 최신 게시물을 주기적으로 수집하고, 1시간 단위로 요약하는 리서치 도구.

## Targets

- @Alisvolatprop12
- @otaku__yuta

## Stack

- Node.js
- Playwright
- Local file storage

## Commands

```bash
pnpm install
pnpm start
pnpm run collect
pnpm run summarize
```
