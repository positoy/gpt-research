# 광주 공식문서 워크플로

## 목적

광주 개발사업의 공식 문서를 시간순으로 축적하고, 새 공식 문서가 생길 때만 반영한다.

## 핵심 원칙

- 정기점검 URL을 상시 확인한다.
- 새 내용이 있으면 유의미성을 먼저 판단한다.
- 유의미한 새 내용이 없으면 아무 것도 갱신하지 않는다.
- 유의미한 새 내용이 있을 때만 원문 저장, 추출, 요약, 통합, 커밋을 진행한다.

## 운영 흐름

### 0. 상시 감시 레이어

- 정기점검 URL을 계속 확인한다.
- 새 항목이 있으면 관련성과 중요도를 먼저 판정한다.
- 유의미한 새 내용이 없으면 아무 것도 갱신하지 않는다.
- 유의미한 새 내용이 있을 때만 다음 단계로 진행한다.

### 1. 상태 점검

- 기존 공식 문서 목록 확인
- 누락된 차수 또는 버전 확인
- 최근 추가된 고시·변경·공고 확인

### 2. 문서 탐색

- 공식 문서는 정기점검 URL과 게시판을 확인
- 상세 페이지와 원문 확보가 필요할 때만 진입

### 2-1. 정기점검 URL

- 고시/공고
  - `https://www.gjcity.go.kr/portal/saeol/gosi/list.do?mId=0202010000`
  - 광주시 일반 고시·공고 목록
- 고시/입찰정보
  - `https://www.gjcity.go.kr/portal/saeol/gosi/list.do?seCode=02&mId=0202030000`
  - 입찰 관련 고시·공고 목록
- 계약정보공개/발주계획
  - `https://www.gjcity.go.kr/portal/nara/plan/list.do?mId=0302010000`
  - 계약·발주계획 공개 목록
- 계약정보공개/조달청입찰정보
  - `https://www.gjcity.go.kr/portal/nara/bid/list.do?mId=0302020100`
  - 조달청 연계 입찰정보 목록
- 계약정보공개/계약정보
  - `https://www.gjcity.go.kr/portal/contract/list.do?mId=0302080100`
  - 광주시 계약현황 목록
- 행정정보/도시계획개발
  - `https://www.gjcity.go.kr/portal/bbs/list.do?ptIdx=29&mId=0301040000`
  - 도시계획개발 / 지구단위계획 / 개발계획 관련 게시판

점검 규칙:

- 마지막 조회 시점 이후의 새 항목만 본다.
- 새 항목이 있으면 유의미성을 먼저 판정한다.
- 유의미한 새 내용이 없으면 커밋하지 않는다.
- 공식 문서만 갱신한다.

### 3. 원본 저장

- 원문 파일을 `official/files/`에 저장
- 가능하면 `YYYYMMDD_한글명` 형식 사용

### 4. Markdown 추출

- HWP / HWPX / PDF는 `kordoc` 우선 사용
- `official/scripted/{원본과 동일한 이름}.md`로 저장

### 5. 요약 작성

- `official/summary/{원본과 동일한 이름}.md`에 한국어 요약 저장
- 변경점과 행정 의미에 집중

### 6. 통합

- `official/report.md`에 문서 메타데이터와 출처 반영
- `official/timeline.md`로 시간순 정리
- `gwangju/master.md`에 공식문서 서술 반영

## 출력 원칙

- 원본, 추출본, 요약본은 분리해서 유지한다.
- 파생 파일은 원본 파일명 기반으로 만든다.
- 가능한 한 정확한 날짜와 차수 정보를 파일명과 요약에 남긴다.
- 정기점검에서 유의미한 새 내용이 없으면 커밋하지 않는다.
