# 광주 연구 허브

광주 개발 연구는 두 축으로 나눈다.

- `official/` — 광주시 공식 문서
- `news/` — 뉴스와 보도자료

공식 문서는 원문 중심으로, 뉴스는 시장 맥락 중심으로 축적한다.

## 공통 원칙

- 공식과 뉴스는 서로 섞지 말고, 각자 별도의 인덱스와 통합 서술을 유지한다.
- 유의미한 새 내용이 없으면 아무 것도 갱신하지 않는다.
- 새 내용이 있을 때만 원문 저장, 추출, 요약, 통합, 커밋을 진행한다.
- 각 워크스페이스의 workflow가 실제 운용 규칙이다.

## 공통 구조

- 원문: `files/`
- 추출본: `scripted/`
- 요약본: `summary/`
- 인덱스: `report.md`
- 연표: `timeline.md`
- 통합 서술: `master.md`

## 하위 워크스페이스

- `official/` — 공식 문서 워크스페이스
- `news/` — 뉴스 워크스페이스

각 워크스페이스는 자체적으로 `files/`, `scripted/`, `summary/`, `report.md`, `timeline.md`를 가진다.
상위 `gwangju/master.md`는 official과 news의 내용을 융합한 사람이 읽기 쉬운 통합 보고서로 유지한다.

## 운영 규칙

- 공식 문서만으로 부족한 맥락은 뉴스로 보완한다.
- 뉴스는 공식 문서의 사실관계와 구분해서 기록한다.
- 뉴스는 본문형 기사면 `files/` 없이도 관리할 수 있다.
- 뉴스 검색 소스는 workflow에 명시적으로 적는다.
- 둘 중 하나에 새 내용이 없으면 그 축에서는 커밋하지 않는다.
