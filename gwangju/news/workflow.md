# 광주 뉴스 워크플로

## 목적

광주 개발시장과 관련 뉴스/보도를 수집해 맥락을 보강한다.

## 핵심 원칙

- 뉴스 검색을 상시 확인한다.
- 새 내용이 있으면 유의미성을 먼저 판단한다.
- 유의미한 새 내용이 없으면 아무 것도 갱신하지 않는다.
- 유의미한 새 내용이 있을 때만 원문 저장, 추출, 요약, 통합, 커밋을 진행한다.
- 뉴스는 공식문서와 구분해서 해석한다.

## 운영 흐름

### 0. 상시 감시 레이어

- 뉴스 검색 결과와 보도 페이지를 계속 확인한다.
- 새 항목이 있으면 관련성과 중요도를 먼저 판정한다.
- 유의미한 새 내용이 없으면 아무 것도 갱신하지 않는다.
- 유의미한 새 내용이 있을 때만 다음 단계로 진행한다.

### 1. 상태 점검

- 기존 뉴스 문서 목록 확인
- 이전에 본 기사와 중복 여부 확인
- 최근 추가된 기사/분석/인터뷰 확인

### 2. 문서 탐색

- 뉴스 검색 결과와 기사 본문을 확인
- 필요할 때만 보도자료, 칼럼, 인터뷰까지 확인
- 본문형 기사면 원문 URL과 추출본 중심으로 관리

### 3. 원문 저장

- 첨부파일이 있으면 `news/files/`에 저장
- 본문형 기사는 파일 없이 URL과 메타만 기록할 수 있음

### 4. Markdown 추출

- HTML 기사 본문은 본문 추출 후 Markdown으로 저장
- 첨부 PDF/HWP/HWPX가 있으면 `kordoc` 우선 사용
- `news/scripted/{원본 또는 제목 기반 이름}.md`로 저장

### 5. 요약 작성

- `news/summary/{원본 또는 제목 기반 이름}.md`에 한국어 요약 저장
- 시장 맥락, 이해관계자 반응, 정책 해석에 집중

### 6. 통합

- `news/report.md`에 기사 메타데이터와 출처 반영
- `news/timeline.md`로 시간순 정리
- `gwangju/master.md`에 뉴스 맥락 반영

## 출력 원칙

- 원문, 추출본, 요약본은 분리해서 유지한다.
- 본문형 뉴스는 `files/` 없이 관리할 수 있다.
- 가능한 한 정확한 날짜와 제목을 파일명과 요약에 남긴다.
- 정기점검에서 유의미한 새 내용이 없으면 커밋하지 않는다.
